# Supplemental third-party license texts

The notice build reads the license and notice files included in each bundled npm dependency. The following npm archives declare a license in their package metadata and omit the full text.

- `@aws-sdk/credential-provider-http`, `@aws-sdk/credential-provider-login`, and `@aws-sdk/nested-clients`. The AWS SDK for JavaScript v3 [license and copyright attribution](https://github.com/aws/aws-sdk-js-v3/blob/main/LICENSE) come from the upstream source repository.
- `uint8arrays@3.0.0`. The upstream [MIT text](https://github.com/achingbrain/uint8arrays/blob/main/LICENSE-MIT) supplements the MIT license declaration in the published package.
- `varint@6.0.0`. The [upstream README](https://github.com/chrisdickinson/varint/blob/7fc8829334c20c4c0e246e3b473c1eb1c03ebbf9/README.md#license) declares MIT. The supplemental text comes from the [SPDX license list](https://github.com/spdx/license-list-data/blob/main/text/MIT.txt). The notices identify the package author from its manifest.
